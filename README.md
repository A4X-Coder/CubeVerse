🌌 CUBEVERSE

Roll. Dodge. Survive.

CUBEVERSE is a 3D endless cube runner where reflexes, timing, and precision determine how long you survive. Dodge obstacles, switch lanes, and push your limits in a neon-inspired universe.

🎮 Play Now

🚀 "Play CUBEVERSE" (https://a4x-coder.github.io/CubeVerse/)

✨ Features

- 🌌 Midnight-blue 3D visual atmosphere
- 🧊 Rolling cube movement and lane transitions
- 🚧 Procedurally generated obstacles
- 📱 Mobile-friendly touch controls
- ⌨️ Keyboard controls for desktop
- 🔊 Sound effects and procedural audio
- 🏆 Local high-score saving
- ⚡ Near-miss effects and collision fragments

🕹️ How to Play

- Dodge incoming obstacles.
- Switch lanes to survive.
- React quickly and keep moving.
- Avoid collisions and beat your high score.

🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Three.js
- Web Audio API

🌐 Play on the Web

No installation required. Open the game in a supported browser and play.
